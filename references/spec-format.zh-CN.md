# 决策清单格式

决策清单记录的是一条提示词背后的决策，与表达这些决策的方言分开存放。先写决策清单，再编译。同一份决策清单换模型时不应该需要重写。

> **本文件只给槽位、判据和结构骨架，不给可抄的元素。** 所有具体案例元素都在隔离区
> [case-library.zh-CN.md](case-library.zh-CN.md)。照[宪法](constitution.zh-CN.md)第二条：
> **先按这里的判据把你自己的槽写出来，写完才打开案例库。**

## 模板

> **先读[宪法](constitution.zh-CN.md)第一组与第二组。** 下面这张表是**可用工具的清单，不是待办清单**：
> 没有任何一槽是必填的，也没有哪一槽的空缺算作缺陷。
> 表中每一槽后面的标记是**该槽通常在什么条件下才值得填**，不是重要性排序。

```text
[① 全局]
  片型：      这是哪一类片子——多轴术语合成 + 参照物锚点 + 各自的配平禁令
  场景：      在哪里、什么时候
  风格：      视觉处理、配色、光的行为（只写看得见的；术语层属于片型）
  导演命题：  一句话——这条片子存在的那个念头
  运镜原则：  管住全片的规则，不是镜头清单
  持续叠层：  〔按需〕每一帧都压在画面上的那一层，以及它自己怎么动
  手法词表：  〔按需〕全片可调用的具名动效与转场，不是逐拍指派

[② 锁]
  身份：      谁或什么必须保持不变，靠哪些不变量
  参考角色：  〔有素材时〕每份素材——控什么，以及不许从它拿什么
  音频源：    原生、外部音轨、还是静音
  配角调度：  〔有配角时〕位置，以及不许做什么
  连续性：    整条片子必须成立的东西
  负向：      〔有内容风险时〕只写具体风险

[③ 时序]
  粒度：      不写 | 分段 | 秒级   （写下面的内容之前先定）
  第 1..n 段：每段一个主要变化
  每段末态：  这一段结束时什么是可见的

[+ 自定义槽]  这条片子需要、而上面装不下的东西（见下节）
```

用不到的字段直接不写。**空着比凑字数好**——每多一行都在跟别的行抢注意力。
**空着也不需要理由**：这条片子不需要它，就是全部的理由。

### 〔按需〕的两槽为什么单独标出来

`持续叠层` 与 `手法词表` 是从某一类高密度平面设计片型里归纳出来的，
对那一类片型它们承载很大比重；**对别的片型它们可能什么都不承载，甚至有害**。

⚠️ 一条实测教训：给一部靠**大色域与极端负空间**讲话的电影填槽时，
照着一部靠**高密度信息叠层**的片子把这两槽填满了，结果是给"空"的片子开了"满"的处方——
每槽都填了、每条末态都达成，方向整个是反的。

所以这两槽填之前先问：**这条片子的观感，是靠画面上信息多，还是靠画面上信息少？**
后者就空着。

## 槽集合是开放的

这张表是**一次归纳的结果，不是穷尽**。遇到装不进任何现有槽的内容，**加一个新槽**，
写在它该属于的那个桶里。

⚠️ **最容易犯的错不是"没有那个槽"，是把它硬塞进最接近的那个槽。**
硬塞就是"放错桶"的变体：内容一旦进了作用域不同的槽，它的作用域就跟着错了。

加槽三问：

1. **它管多大范围？** 整片 → 桶①；不许漂 → 桶②；某一拍 → 桶③
2. **现有哪个槽作用域跟它相同？** 有 → 用那个槽，别新建。没有 → 新建
3. **它能不能被检查？** 不能 → 先按[可验证性](verifiability.zh-CN.md)改写成可观察的结果

防膨胀的门槛：**说不出这个新槽"管什么、以及跟哪个现有槽不同"，就不要建它。**

常见的合理新槽（举例，不是清单）：`材质`、`字幕与画面内文字`、`音乐结构`、`色彩脚本`、
`光的行为`、`成片交付规格`。它们在某些片子里是独立作用域，在别的片子里根本不存在。

## 字段说明

### 片型（桶①）

**不是一个标签，是一次多轴合成。** 弱的片型读起来像分类名（`一条极简扁平矢量的片头`）,有效的片型给出这条片子在行业里的坐标:

> **合成的形状取自实际跑通的提示词，是描述性的;「合成比标签更有效」这个因果关系尚未隔离验证** —— 观察到的对照里，风格词与其他六七处改动是同时变的。当作带理由的默认值用。

```text
片型：  <这条片子在行业里的品类名>
        <媒介／技法术语> + <构图语法术语> + <元素语汇术语>
        参考<参照物品类>
        配平：<针对上述各术语默认偏置的定向禁令>
```

三条写法:

**一个术语占一根轴，别同义堆叠。** 「媒介/技法」「构图语法」「元素语汇」是三根不同的轴。三个词都在说「看起来什么样」等于只说了一件事，还互相抢注意力。

**术语要有真实语料，不能是自己造的短语。** 判据：这个词在行业里能不能搜到、并且底下挂着一大批被这样标注的作品？能→是术语；不能→是描述，那属于「风格」槽。

**加一个参照物锚点。** 指向一类真实存在的成品品类（海报、杂志内页、赛事主视觉）,比任何形容词都强。别指具体作品或作者名。

#### 配平禁令

**每个具名术语都是一笔带利息的贷款。** 你借它的美术先验，就得连带接受它的默认偏置。配平禁令是**定向抵消那些偏置、同时把术语留着**的几条禁令。

形状是这样（**示意，不是默认值**——照[宪法](constitution.zh-CN.md)第一条，别把下面的元素带进你的决策清单）：

```text
<你选的具名术语>   ← 借:<它带来的美术先验>   偏置:<它默认会拽向哪里>
配平:<定向抵消那个偏置的几条禁令，成组>
```

**配平不是否定术语**：术语留着（它带来的美术先验是你要的），
只把它顺带拖来的那几样副作用定向抵消掉。

填的动作是三步：**①这个术语在行业里默认长什么样 → ②那个默认里哪几样是我不要的 → ③逐样写成禁令。**
第①步必须诚实——想不出这个术语的默认样貌，说明你还不该用它。

（两个题材的填好实例 → 案例库 B1、D5）

**借和还写在一起，写在这个槽里，不要丢进「负向」槽。** 理由：配平禁令只对**它配平的那个术语**有效。一旦离开术语被集中存放，换片型时会被整块抄走，退化成通用黑名单——而那正是提示词变长却没变好的主要成因。

> **这一条是带理由的默认值，不是已验证规则。** 观察到的两份真值里，一份把配平禁令紧贴术语放在开头，另一份把同类内容放在结尾的负向段——**作者自己不一致**。选「紧贴」的理由是上一段那个可迁移性论证，不是实测对照。

删掉术语来避开偏置是下策：偏置没了，先要的美术先验也没了。**配平优于删词。**

配平禁令的**条数与措辞是模型相关的**,属于[模型档案](model-profile-schema.zh-CN.md);「哪个术语需要配平」这件事本身与模型无关。

### 导演命题（桶①）

一句话。要写两句说明这是两条片子。命题是「只能留一行时你会留的那行」，也是锁与锁冲突时的裁决依据。

弱的命题读起来像类型标签（`一条电影感的产品片`）。
有效的命题点出**那个具体的念头**，而且通常长成「因为 X，所以画面必须 Y」——
它把一个物理事实和一个视觉决定绑在一起，于是后面每条锁都能从它推出来。（实例 → 案例库 A6）

**但这一槽不是必填的**（[宪法](constitution.zh-CN.md)第五条）。它是「唯一不能从别处推出来的槽」——
那是说它**不可替代**，不是说它**必填**。案例库 C 那条片子整份决策清单没有这一槽，跑通了。

⚠️ **写进这一槽的应该是「为什么」，不是「每次都要做什么」。**
一条执行规则（"每段之后都要做 X"）被写进命题槽会**获得命题的权威性，于是变成不可违反的**，
跟它自己的执行方式打架。规则属于手法词表或时序槽。（踩坑记录 → 案例库 C）

### 持续叠层（桶①，〔按需〕）

**先判断要不要这一槽。** 见上文〔按需〕那一节：这条片子的观感靠画面上信息多，还是靠信息少？
靠少 → 空着，不要往下读。

要填的话，写两半：**这一层由什么组成**，以及**它自己怎么动**。
只写组成会得到一张贴纸；**动起来才是叠层**。

⚠️ 这两半里第二半最常写坏。「随镜头轻微视差位移、持续扫动」这类句子**不可验证**，
生成出来就是静态贴纸。每一项都要给可数的运动量：多久跳一次、每秒几次、滚多快。

```text
持续叠层：<这一层由哪几样东西组成>
          <每一样各自怎么动，带可数的量>
```

**选元素之前先答一个问题：这一层在这条片子里承担什么功能？**
元素从那个功能长出来，不从「这类片子通常压什么」长出来。
说不出功能就先别选元素——那说明这一槽你还没想清楚，此时挑到的会是见过的那套。

（同一条 DNA、两个不同动作的填法对照 → 案例库 B2 与 B4。**那两套元素零重叠**，是"元素是皮"的直接证据）

**决定要填之后，这一槽必须在桶①。** 写进某一段，下一段就没有了——
观众看到的是那一层突然消失。

**还有一层判断：叠层不只有"要不要"，还有"会不会伤害这条片子"。**
靠负空间和大色域讲话的片子，加一层持续信息会直接削掉它的呼吸。

### 手法词表（桶①，〔按需〕）

全片**可调用**的具名动效与转场清单。它和桶③ 的「这个切点用哪一个」是两件事：词表是库，逐拍指派是取用。

**先判断要不要。** 这一槽只在「一套固定手法反复出现」本身构成风格时才有价值。
一条以单一长镜头或自然衔接为骨架的片子，这一槽是噪音。

#### ⭐ 决定要填之后，先问来源域

**每个槽都有自己的来源域，不同槽的来源域可以不同源。**

| 槽 | 它的来源域是 |
|---|---|
| 片型术语 | 这条片子的**画面**属于哪个体系 |
| **手法词表** | 这条片子的**动态**属于哪个体系 |

这两个问题的答案**经常不是同一个体系**。而如果不分开问，你会从定好画面的那个体系里
顺手取动态词——**那是本 skill 记录过的一次三版弯路**：一条片子的画面体系定对了，
但接下来三版都在**同一个体系**里找动态工具，加什么都上不去；
换到另一个体系的语汇库之后一次就成了。（两个体系各自的具名手法 → 案例库 B3、E4）

所以顺序是：**先说出这条片子的动态属于哪个体系，再在那个体系里取具名手法。**
说不出体系名就先别填这一槽——那说明你还没想清楚它靠什么动。

```text
手法词表：<这条片子允许反复使用的几个具名手法>
          <转场只允许用哪几类>
          禁用：<这条片子明确不要的那些手法>
```

（两个题材的填好实例 → 案例库 B3、D6）

三条写法：

- **用具名术语，别用现象描述。** 一个行业里有名字的手法，比把它的现象描述一遍更能调用模型先验。识别度不确定时按 [portability.zh-CN.md](portability.zh-CN.md) 的术语＋可观察描述双写（实例 → 案例库 B3、D6）
- **禁用槽写的是「这条片子不要什么」，不是「别的工具做这个更便宜」。** 后者是生产流程判断，
  本 skill 不做流程判断；预先划走一类手法，等于永远测不到模型在那一类上的能力
- **运镜原则管镜头怎么动，手法词表管画面怎么变。** 两槽不要混填

### 参考素材角色（桶②）

永远两半。控什么，以及不许从它漏什么：

```text
<素材> 控 <这份素材唯一负责的那几样>。不要用它的 <最容易漏进来的那几样>。
```

（三种模态各一例 → 案例库 D4）

**每个主体单独命名、单独绑定。** 绝不要写「@image1 到 @image4 分别定义四个角色」——那等于什么映射都没说。

几张图拍同一个物体的不同角度时，要明说，并写明输出数量：`四张图定义的是同一盏灯。全片只出现一盏灯。`

### 负向（桶②）

写具体风险，不是常备黑名单。一条负向值得留，当它命名的是**这条片子真的可能产出、而且重做很贵**的东西。抄别人的负向清单，是提示词变长却没变好的主要原因。

#### 先路由，再决定要不要写

一条候选负向，先问它在配平什么，按来源送到对应的槽:

| 它在配平的是 | 送去 |
|---|---|
| **你自己选的某个具名术语的偏置** | 片型槽的[配平禁令](#配平禁令) |
| **调色板 / 身份 / 全片必须成立的东西** | 桶② 的连续性、身份等对应槽 |
| **这条片子的内容本身可能产出、而且重做很贵的东西** | **留在这里。这才是负向** |

**真负向长什么样**:它配平的是**这条片子的某个具体内容**可能产出的风险，不指向任何术语——
换掉风格词，那个风险照样存在。（实例 → 案例库 C）

**这一槽不一定要填。** 有那类内容风险就写，没有就空着——空着是路由的正确结果，不是漏填。反过来，如果你发现自己在这里堆了很多条，先跑一遍上面的路由：多半有一批是配平禁令穿了负向的马甲。

一次实测：把一份跑得很好的提示词里整段【严格限制】逐条追来源,**那十条全部路由到了别处**,
负向槽最后是空的。**这是那条片子的结果，不是普遍规律**——换个题材就会有真负向。
（逐条追溯表 → 案例库 B5）

**必须指名，不能凭印象判空。** 一条负向的来源常常不是你第一个想到的那个:
一条看着像在配平某个场景设定的负向，实际配平的可能是**片型术语本身**——
哪怕片子里根本没有那个场景，只要那个术语还在片型槽里，这条负向就仍然有效。

留下来的负向要能通过一个检查:**指名它配平的是哪个术语或哪条设定，然后确认那个东西在这份决策清单里存在。**
指名之后确实找不到对应物的，才是死重，删掉。

负向也是模型相关的，见 [portability.zh-CN.md](portability.zh-CN.md)。

### 末态（桶③）

整份决策清单里杠杆最大的字段。见 [verifiability.zh-CN.md](verifiability.zh-CN.md)。

## 所有槽里的禁令，都要过这三问

⚠️ **这一节的作用域是整份决策清单，不只是上面那个负向槽。**
片型槽的配平禁令、连续性里的「不许」、动画方式里的「不要」、参考素材的「不要用它的」——
每一条禁令都适用。

**要达到的效果，优先用正向写。** 说清楚要什么比列出不要什么更能落地
（理由见 [verifiability](verifiability.zh-CN.md) 的「用画面写，规格定义作保险」）。
一条禁令只在**不写就会发生、而且发生了很贵**的时候才值得加。

1. **不写它会发生吗？** 很多东西不写根本不会发生 —— **不写 ≈ 负向**。
   这时候写禁令是纯成本：占预算、跟别的行抢注意力，还可能连你要的东西一起挡掉
2. **发生了有多严重？** 重做很贵、或者破坏这条片子的核心概念 → 加。
   只是"不够好看" → 不加，下一版在皮上改就是了
3. **如果模型把这条禁令理解成「这一整类都不要」，我还接受吗？**
   前两问决定**加不加**，这一问决定**怎么写**。见下。

### 第三问：禁令的作用范围会被放大到它所属的那一类

**你写的是一个点，模型执行的可能是这个点所在的那条轴。**

两个不同维度的实例，机制相同，**但证据强度不同**：

| 写下的禁令 | 想抵消的 | 被放大成 | 证据 |
|---|---|---|---|
| 「不要三维」 | 三维**渲染方式**（体积光、材质反射、软投影） | 整条**空间**轴——连平面绘画自己的纵深手段一起没了 | ✅ **实测**：画面逐条合格但扁平单调；另一条参考片证明纯平面画法可以有真实纵深 |
| 「没有音乐」 | **旋律性配乐** | 可能是整条**音频**轴——连环境音、点状音效一起静音 | ⚠️ **未实测**：删掉该段之后模型自带的音乐与音效跟着剧情走、效果好；但没有跑"保留该段"的对照 |

一个具名术语的偏置是「往某个方向拽」，你要抵消的是**那个方向**，不是**那条轴上的全部**。

**修法不是删掉禁令，是把想留下的那半正面写出来**：

```text
弱：  没有音乐
强：  要环境音与点状音效，不要旋律性配乐

弱：  不要三维
强：  渲染方式是平涂色块、无体积光与材质反射；空间保持真实纵深与前后遮挡
```

⚠️ **这类失败比"禁不住"更难发现。** 禁不住是画风漂了、一眼看得见；
禁过头是**该有的东西没出现**——逐条检查全部合格，打勾表满分。
它跟[宪法](constitution.zh-CN.md)第十条那条「少写在输出里没有痕迹」是同构的，
只是发生在禁令这一层：**你以为自己只关了一盏灯，实际拉了闸。**

### ⚠️ 与宪法第十条的边界

[宪法](constitution.zh-CN.md)第十条是**单向**的：只禁「因为觉得模型做不好而少写」。
本节看起来像在鼓励少写，两者必须划清 —— **区分点是正向还是禁令**：

| | 默认 | 理由 |
|---|---|---|
| **正向描述**（要什么） | **宁多勿少**（宪法第十条） | 少写在输出里**没有痕迹**，代价高一个量级 |
| **禁令**（不要什么） | **按严重程度筛**（本节） | 写多了看得见、能删，但不是零成本 |

严重程度分档直接沿用宪法第十条那张表：**用户强调过的少写了＝最严重 / 没强调、看完才发现想要＝在皮上加 / 写多了＝轻。**

两条合起来才是完整的取舍：第十条讲少写的代价，本节讲多写的代价。

## 多段接龙（只在有上一段时适用）

⚠️ **作用域**：这一节只对**接在别的生成产物之后**的段落成立——
第一段、单段片子、无接龙的多镜头一律不适用（[宪法](constitution.zh-CN.md)第十一条）。

上一段的末态是这一段的**既成条件**（given），不是这一段的全部锁——
桶①② 照常从零写全，该重写的术语、视差、身份一样不能省。

### 开写前先看，然后对每个主体二选一

```text
延续：明写它继续存在，以及它在新条件下靠什么继续可读
清除：明写它消失，以及本段不再出现该物 / 同类物 / 该类别
```

**两者都不写 = 它会被保持，而且可能被放大。** 这是这一节存在的唯一理由。

两个填好的模板 → 案例库 E7。那里也记着反面：
一次「A 的轮廓线拉伸变形成为 B」的写法，被执行成了**把 A 放大**——
要求 A→B 的变形，但指定的机制是"同一条线拉伸"，而那个机制的物理结果是 A 变大。

### 由此推出的两条

- **末态槽在接龙场景下权重更高。** 它不只是这一段的收束，还是下一段唯一继承到的视觉条件
- **任何未指定的槽会沿链往下传。** 某一段没写明的东西，模型替你填了，
  然后它进入尾帧，成为下一段的既成条件——偏差在链上会累积而不是自行消失
  （实例 → [observations](observations.zh-CN.md) 的"未指定的槽位由模型自己填"）

### ⚠️ 接龙不是延长，两者的默认值方向相反

| | 接缝该是什么 |
|---|---|
| **延长 / 续写**（时间上继续同一个镜头） | 缝要藏起来 |
| **接龙**（叙事上换段落，只借一张首帧） | **缝就是硬切**，是手法本身 |

把其中一种的默认值套到另一种上，是[宪法](constitution.zh-CN.md)第十一条那个错误的现成陷阱——
两个场景名字相近、默认值相反。

## 两条书写约定

这两条管的是文字放在哪，不是写什么。

**把两三条最贵的锁在物理结尾复述一次。** 近因效应有用。这不是第四个桶——内容仍属桶①②，并且先在那里出现过。复述两三条，不是整张清单。

**当由模型替你写决策清单时，明写输出顺序。** 不指定顺序，桶与桶会串味：全局规则跑进第 3 拍，锁被当成事件重述。把段落名称和顺序写进指令里。

## 常见失败

| 症状 | 成因 | 修法 |
|---|---|---|
| 风格前面守住、后面漂了 | 全局规则被写进了第 1 段里 | 移到桶① |
| 模型造出多余的停顿 | 对连续动作用了秒级粒度 | 降到分段或不写时序 |
| 参考素材的背景漏进来 | 角色只写了一半 | 补上「不许拿什么」那半 |
| 两个主体融合或互换 | 按组绑定而非逐个绑定 | 一个主体一行绑定 |
| 提示词很长、结果很弱 | 用形容词堆替代了导演命题 | 把那一句话写出来 |
| 片子结束时没有收束 | 最后一段没写末态 | 写明收尾的可见状态 |
| 叠层前几拍在、后面消失 | 叠层写进了某一段 | 移到桶① 的持续叠层槽 |
| 叠层出来是静态贴纸 | 运动那半写成了不可验证的句子（「随镜头轻微位移」「持续扫动」） | 每一项给可数的运动量：多久跳一次、每秒几次、滚多快 |
| 每条末态都达成了，整片却平淡 | **有好几种可能。不要默认归因到某个空槽** | 按这个顺序排查：①**每一镜内部有几件事在同时变化**——平淡常常是镜内单层，跟填了几个槽无关；②片型术语是不是抄了另一部片子的（见下一行）；③命题是不是写成了类型标签 |
| **每条锁都守住了、每条末态都达成了，但美术方向整个是别人的** | **片型术语整套来自另一部片子** | 术语合成必须从这条片子重新长出来。**这是最隐蔽的一类失败**：所有锁都在生效，生效的是另一部片子的方向，逐条检查不可能发现，只能把术语跟片子的视觉语言对一遍 |
| 给"空"的片子开了"满"的处方 | 照着一部高信息密度的片子填了〔按需〕两槽 | 回到上文那一问：这条片子的观感靠信息多还是信息少 |
