# 案例库（隔离区）

> # ⛔ 读这份文件之前，先把你自己的槽写完。
>
> 这里的每一个具体元素——术语字符串、禁令措辞、叠层清单、质感词、分镜写法——
> 都是**某一部特定片子的皮**。它们对那部片子成立，对你的片子**默认不成立**。
>
> [宪法](constitution.zh-CN.md)第一、二条在这里是硬约束：
> **先只看你的片子把槽写出来，写完之后才允许打开这份文件**，
> 用途只有两个：检查有没有漏掉一整类东西、检查措辞够不够可验证。
>
> **判据**：把这份文件整个删掉，你还能不能凭你的片子本身写出那一槽？
> 不能 → 你还没想清楚，此时抄这里只是把空白掩盖过去。
>
> 本库**按片子分组，不按槽分组**——这是故意的。
> 要用某一条，你得先承认"我的片子和这部是同一类"。这个动作本身就是筛子。

各条原理的正文在 [verifiability](verifiability.zh-CN.md) 与 [spec-format](spec-format.zh-CN.md)，
那里只讲**失败的形状**（不可抄，只能理解）；可被抄的元素全部在这里。

## 案例 A · 实拍 × 自发光手绘 VFX（夜间恐龙博物馆）

四模型对照跑过，prompt 迭代到 v5。这部片子贡献了 skill 里最多的方法论结论。

### A1 · 质感锁的演化（对应「挑那条真正承载概念的属性」）

需求：手绘层必须保持手绘感。三个版本：

```text
v1（失败）：手绘形体保持平面图形，绝不渲染成写实生物
v3（成功）：蜡笔、粉笔、彩铅、粗笔刷；看得见排线方向、涂色不均、毛边
```

v1 可检查、毫不含糊，**两个不同模型都严格照做了**——给出光滑矢量霓虹描边加均匀填充。
平面？是。手绘？完全不是。锁测的是**平面性**，真正承载概念的属性是**看得见工具痕迹**。

### A2 · 机制那一次（对应「写明机制，不只写效果」）

需求：末段一张巨大的手绘嘴要有压迫感。

```text
A（好）：张开的上下颚横跨整片天顶
B（差）：头颅在大厅正中浮现，正面朝向摄影机，上下颚大张，獠牙从画面上下两侧逼近
```

B 听起来更凶，结果更差：手绘的嘴变成写实立体头骨。
删掉 `横跨整片天顶` 等于删掉画面里唯一的**尺度参照**，模型只能改走**体积**那条路，
而体积需要实体感，于是把整条片子依赖的平面手绘锁撞碎了。

**同一句 `横跨整片天顶` 也不是普遍有效的**：在圆形穹顶的场景里生效，在方形吊顶的场景里落空。
机制依赖的参照结构必须真的存在于场景设定里。

### A3 · 画面语言 vs 规格语言（对应「用画面写，规格定义作保险」）

| 写成画面——能落地 | 写成规格——需要翻译 |
|---|---|
| `蜡笔、彩铅，看得见排线方向、毛边` | `保持平面图形质感` |
| `穹顶被画成一只巨大的手绘恐龙头颅轮廓` | `贴在穹顶上的平面图形，不是有体积的立体头骨` |
| `白色三角獠牙沿着穹顶边缘一排排展开` | `宽度横跨整片天顶，几乎和穹顶一样大` |

最强的版本**两者都用**（画面先行，规格追加）：

```text
穹顶被画成一只巨大的手绘恐龙头颅轮廓，张开的上下颚横跨整片天顶，白色三角獠牙
沿着穹顶边缘一排排展开。……嘴的线条保持蜡笔的毛边和逐帧抖动，始终是贴在穹顶上
画出来的平面图形，不是一个有体积的立体头骨。
```

三种写法实测：只有规格定义 → 写实头骨（失败）；规格为主 → 对但啰嗦；**画面先行＋规格追加 → 最好**。

### A4 · 噪音的判据（对应「一行字该不该留」）

```text
留：  骨架缝隙之间钻出好几只白色的小手绘恐龙
删：  ……衬得大骨架格外巨大
```

尺度对比是「小生物在大骨架上」的必然结果，写出来只增加长度、不增加约束。
实测删掉之后毫无变化。**噪音不是长度，噪音是重述。**

反过来，同一条片子里三处**因为写长了才成立**：按工具命名的媒介、
救回某个模型质感的逐段复述、明写的「开放式展台、没有玻璃罩」。

### A5 · 交出「要什么」，别交「怎么做」

把化石展板写成「竖立的长方形」，效果**不如**不写形状——
模型自己读成拱门形壁龛，跟建筑结构呼应得更好。

### A6 · 这个片型的 DNA 与皮

DNA 五条：POV 手持迟一步追（不切镜头）／实拍的手触发诞生／手绘媒介按工具命名＋弱辉光／
寄生宿主并不断换宿主／末段升格整个空间。

宿主关系两种：**附着 vs 替代**（实拍物本身变成手绘物），后者更强。

**皮**：空间、画什么、配色、哪些结构当宿主、最后升格成什么。

⚠️ 一次早期换皮的教训：把自发光媒介换成吸光媒介（水墨），于是被迫反转布光（明亮书房）。
内部逻辑无懈可击，但弱辉光在亮底上没有东西可读，镜头同时也变成固定机位（破了 DNA 第一条）。
成片是雅致而不是超现实——**概念还成立（removal test 第 1 问过了），想看它的理由没了（第 2 问没过）。**

**那一版的导演命题（一句话的写法样本）**：

```text
导演命题：墨不发光、它靠吸，所以房间必须亮到能让黑读出来
```

它长成「**因为 X，所以画面必须 Y**」——把一个物理事实（墨是吸光的）和一个视觉决定（房间要亮）
绑在一起，后面每条锁都能从它推出来。⚠️ 但也正是这一句暴露了换皮的问题：
**命题本身推导严密，推错的是上一步**——把"自发光"当成了皮。
**命题只能保证内部自洽，不能保证换对了 DNA。**

## 案例 B · 平面设计式 PV 片头（抽象标本机构）

⚠️ **这部片子的元素被误抄过一次，是 skill 里代价最高的一次错误。**
详见 [film-type-dna](film-type-dna.zh-CN.md) 的「实测：两次照抄」。看这一节时格外注意隔离。

### B1 · 片型术语合成 + 配平禁令

```text
纯二维日系赛璐璐动画 + 抽象 Editorial MG 平面设计 + 游戏UI平面设计
参考高级游戏宣传海报与动态平面动画语言
配平：禁止任何3D效果 / 禁止立体建模 / 禁止真实空间纵深 /
      禁止三维透视渲染 / 禁止CG质感
```

借的是造型质量，偏置是往立体走。三点对照：
保留术语 → 画风漂（肤色＋渐变＋高光）；删掉术语 → 画风回来但丢造型质量；
**保留＋成组定向禁令 → 两者都要到**。

> ⛔ 这套术语**只对这一部片子成立**。它指向「高密度信息叠层＋高饱和三色」；
> 换到靠大色域与负空间讲话的片子上会整个错配。**术语合成是皮，必须从你的片子重新长。**

### B2 · 叠层元素（这套系统在「量」）

```text
浅灰极细制图网格线 / 十字定位标记 / 四角取景括号 / 边缘小号数字刻度标尺 /
圆形刻度盘与量角器弧线 / 细线准星瞄准框
—— 始终存在，随镜头轻微视差位移，刻度盘指针与弧线持续扫动
```

这套是**测量语汇**，因为那部片子的主题是测量一个静物。
⛔ 换片子必须重问：**这条片子里的那套系统在做什么动作？**（量／找／追／播／审／记）

一个对照的填法见 B4。

### B3 · 手法词表

```text
斜向擦除 / 圆环扩张 / 剪影反相 / 图形拆解 / 单帧白闪 / 残影 / 短促 Glitch
转场只用剪影、色块遮罩、黑白反相与图形匹配
禁用：普通淡入淡出、无意义快切
```

### B4 · 同一 DNA、不同动作的叠层（检索语汇）

另一部片子（一部电影的二维改编）主题是**在人群里检索一个人**，同一个叠层槽填出来完全不同：

```text
ESPER 式检索方框——每半秒跳到画面另一处，框内区域放大一档
左右边缘各一列竖排字符——持续上滚，每秒约三分之一屏高
底部音频波形条——每秒起伏四到六次
眼球旁的短序列号——出现即固定
全息掉帧——每两三帧一次 RGB 一格错位
```

**对照 B2 看**：同一条 DNA，两套元素零重叠。这就是"元素是皮"的证据。
另外注意运动量的写法：B2 那句「随镜头轻微视差位移、持续扫动」**不可验证**，
实测生成出来是静态贴纸；B4 每项都给了可数的量。

### B5 · 负向路由的实例

把这部片子里跑得很好的一整段【严格限制】逐条追来源，**十条全部路由到了别处**：

| 那条负向 | 实际在配平什么 | 该去哪 |
|---|---|---|
| 不要写实光影 / 立体3D / 真实透视 / 皮肤色 / 渐变 / 高光 | 「二维赛璐璐动画」这个术语 | 片型槽 |
| 不要战斗番 / 不要复杂连续打斗 | 「赛璐璐 + 宣传PV」 | 片型槽 |
| 不要大面积霓虹灯 / 不要赛博朋克街景 | 「游戏宣传PV」——**不是片中的城市，片里根本没有城市** | 片型槽 |
| 不要任何文字、字母、数字 | 「游戏UI平面设计 + Editorial MG」（两者都推文字） | 片型槽 |
| 不要第四个色相 | 调色板锁，不是内容风险 | 桶② 连续性 |

那份决策清单恰好没有内容风险类的负向，所以负向槽是空的。
**这是那条片子的结果，不是普遍规律。** 换个题材（例如墨扩散那类）就会有。

**必须指名，不能凭印象判空**：「不要霓虹灯与赛博朋克街景」看着像在配平城市设定，
实际配平的是**片型术语本身**。片里没有城市，但只要那个术语还在，这条负向就仍然有效。

### B6 · 这个片型的 DNA、粒度与皮

见 [film-type-dna](film-type-dna.zh-CN.md) 的「平面设计式 PV 片头」条目——
那里的皮清单有九项，**一项都不许继承**。

## 案例 C · 手绘绘本 × GUI 光标（一只猫和一个不属于这幅画的东西）

一份完整的决策清单填写示例，**桶① 七槽里填了六槽、空着一槽**。R2V，16:9，30s。
**看它的结构，不要拿它的内容。**

这一条也是本库里唯一**从零走完隔离流程**的片子：先只看参考片与题材把槽填完落盘，
写完之后才打开本文件与片型库（[宪法](constitution.zh-CN.md)第二条）。

```text
[① 全局]
  片型：     不透明水粉厚涂的儿童绘本插画
             ＋ 真实纵深的居家空间（前中远三层，越远越浅淡）
             ＋ 植物环绕的居家静物语汇
             参照物锚点：一页儿童绘本的整页插图
             配平：颜色是一层层盖上去的不透明色块，边缘是笔停下的地方，
                   看得见笔毛分叉与纸面颗粒——不是透明叠色，没有湿边晕染；
                   毛是短促干笔颗粒堆出来的色块，不是一根根毛发丝

  场景：     一整个家，房间由门洞与走廊真实连通：
             客厅 → 走廊 → 厨房 → 卧室 → 书房 → 窗台。每个房间都塞满绿植

  风格：     灰绿墙面、米黄编织地毯、深绿家具、赭黄陶罐、木色地板、奶油白窗光
             橘猫是画面唯一的暖色主体；红毛线团是唯一的纯饱和红
             每个形体分受光面与背光面两块硬边色块；没有描边线，没有渐变过渡

  导演命题： 〔空着〕—— 见下方说明，这一槽这条片子没填，跑通了

  运镜原则： 镜头跟着猫走，可推近、可拉远、可横移、可穿过门洞。
             运动要有目的：推近为了看清一个动作，拉远为了亮出整个房间。
             不摇晃、不旋转、没有理由的持续漂移。除两处指定特写外全片一个连续镜头

  持续叠层： 一个白色、黑描边的经典电脑箭头指针，位图锯齿边缘，不抗锯齿。
             它是画面里唯一不属于这幅画的东西，永远贴在画面表面，不随远近改变大小。
             第二秒起全片在画面内一次都不离开；移动是一小段一小段的直线位移，
             到位后完全静止，不走平滑曲线

  手法词表： 每一帧重画，所有轮廓持续轻微抖动；表情整帧替换不做形变过渡；
             惊吓与爆发单帧切入不留过渡帧；被碰到的部位压扁再弹回，2–3 帧完成
             禁用：平滑缓动插值、运动模糊、粒子特效
             神态表（六种，逐段指派，每种都写成"哪几样部件变成什么形状"）：
               好奇／惊讶／不小心／生气／炸毛／晕圈
             幅度收着用：不要獠牙，不要闪电，不要变形到认不出这只猫

[② 锁]
  身份：     身体是圆角宽椭圆，没有可见的脖子；前爪是两个浅色小方块；
             耳朵两个实心三角，内侧一块浅色；眼睛白色杏仁形＋琥珀虹膜＋黑色竖瞳；
             鼻子一个深红小菱形；每边三到四根白色细胡须；橘色虎斑＋奶油色胸腹

  参考角色： @Image1 控画风与质感、配色、猫的造型语言、屋内物件的造型。
             不要用它的构图取景，也不要用它的空间关系——片中的空间有真实纵深

  音频源：   原生。**只写"用原生音频"，不写具体内容**——见下方说明

  配角调度： 物件位置固定；只有被光标碰到的那一件有反应，其余保持静止；
             物件不许拟人化——不长眼睛、不长嘴、不做表情

  连续性：   换房间时猫的造型、画风、纸张颗粒质感完全不变，只有场景换。
             全片只有一只猫。画面里没有人，也没有人的手。
             光标的形状始终是那个箭头，不变成手形或其他图标

  负向：     猫直立站起来；猫用前爪像人手一样操作物件

[③ 时序]
  粒度：     分段（长保持＋少数几个突发点。秒级会把保持切碎）
  第 1 段：  客厅打盹，光标滑进来 → 末态：抬头，一耳向前一耳向后，头歪，瞳孔放大；
             光标停在红毛线团正上方
  第 2 段：  扑向毛线团抱住翻滚 → 末态：侧躺，两前爪抱着毛线团；线拖到画面左缘
  第 3 段：  追光标冲上走廊，四脚打滑 → 末态：刹住，四腿岔开撑地；
             两眼是纯白大圆，胡须全部外张；尽头看得见厨房门
  第 4 段：  跳上厨房台面撞倒陶罐 → 末态：罐子倒了一排，两个落地；
             猫两前爪并拢抱胸，耳朵后压
  第 5 段：  伸爪够水槽，被水滴砸中缩回 → 末态：两前爪抱胸，眉毛压成八字，
             瞳孔缩成竖线，尾毛炸开；水槽边一小滩水
  第 6 段：  卧室，一头扑进被窝 → 末态：被面下鼓起一个会动的包，
             一条橘色尾巴露在被子边
  第 7 段：  跳上书架拨倒一排书 → 末态：书歪出来往外倒，几本掉地摊开；
             猫站在隔板上，头歪向一侧
  第 8 段：  撞进窗台花盆堆（中途一个特写）→ 末态：花盆倒了几个，叶土散落；
             猫整个埋进叶堆，只露一条炸开的尾巴
  第 9 段：  顶出头，光标停到鼻尖上（一个正面特写）→ 末态：头顶盖着一片叶子；
             光标停在鼻尖；两眼向内聚成斗鸡眼；其余一切静止
```

注意里面**没有**什么：没有每镜时长、没有逐段的运镜词汇、没有形容词堆。
命题承载观感，末态承载结构。

**⚠️ 秒数是被主动移出去的**，不是忘了写。这份决策清单早期版本每段都带秒数（`0–4s`／`4–9s`…），
对照 [spec-format](spec-format.zh-CN.md) 常见失败表里那条「模型造出多余的停顿 ← 对连续动作用了秒级粒度」
之后移除。段序保留，秒数只留在作者自己排结构的草稿里。

**⚠️ 第 2、6 段没有指派神态，是判断结果不是漏填。**
每段都塞表情会让它变成表情包串烧，反应就不值钱了——留白是为了让第 8、9 段那两个夸张的显得重。
这是「没有必填」在段落层面的同一个动作。

**这里的负向是真负向的样子**：「猫直立站起来 / 用前爪像人手一样操作物件」配平的是
**"猫"这个内容本身**可能产出的风险，不指向任何术语——换掉画风词，那个风险照样存在。
（路由过程：写实猫毛、三维渲染、透视线全部去了片型槽的配平禁令；
光标不许变形去了连续性。留在负向槽的只有这两条。）

### ⭐ 这条片子最值得看的两处，都是「空着」

**① 导演命题空着，跑通了。**
[spec-format](spec-format.zh-CN.md) 与 [slot-filling](slot-filling.zh-CN.md) 都把命题写成
「唯一不能从别处推出来的槽」——那是说它**不可替代**，不是说它**必填**。
这条片子从头到尾没有这一槽，九段的取舍靠的是「节奏是一条波浪线」那条运镜/节奏描述在裁决。

⚠️ **一次真实的踩坑记在这里**：整理这份案例时曾给它补过一句命题，写成
「……所以每闯完一次祸，**必须**先给一个反应表情」。作者一眼判为"太满"。
拆开看，那句话把**执行规则**塞进了**命题槽**：

| | 内容 | 该在哪 |
|---|---|---|
| 念头 | 好笑的是猫对刚发生的事的反应，不是猫做了什么 | 命题 |
| 由念头推出的规则 | 每段动作之后给一个反应表情 | 手法词表 / 时序 |

**后果是规则获得了命题的权威性，于是变成不可违反的。** 而这份决策清单自己的逐段指派里
第 2、6 段本来就是空的——规则一旦被写成「必须」，就跟它自己的执行方式打架了。
**判据：写进命题槽的东西，应该是"为什么"，不是"每次都要做什么"。**

**② 音频源只写了"原生"，没写内容——而这正是它成立的原因。**
这条片子的早期版本写过一整段音频指令，其中包含 `没有音乐，没有旁白`。
后续版本把整段删掉，只保留"用原生音频"。**成片里模型自己给出的音乐与音效跟着剧情走，作者认为效果好。**

如果保留早期那段，丢掉的**很可能不止那条音乐**。

⚠️ **「没有音乐」这类否定式指令，模型可能把它读成一整类的关闭**——
无音乐 → 连带无环境音、无点状音效，整条音频轴一起静音。
**禁令写的是一个点，模型执行的却是这个点所在的那条轴。**

所以这不是"运气好，没写反而更好"，而是一条可复述的机制：
**否定式指令的作用范围会被放大到它所属的类别。**
判据：写一条禁令之前问一句——**如果模型把这条禁令理解成"这一整类都不要"，我还接受吗？**
不接受，就不能只写否定，要把想留下的那部分正面写出来（例如"要环境音与点状音效，不要旋律性配乐"）。

（模型侧的行为记录属于观测，不属于本文件 → [observations](observations.zh-CN.md)）

## 案例 D · 零散小例（不属于任何一部完整片子）

> ⚠️ **本节与 A/B/C/E 不同：这六条没有跑过，只示范形状。**
>
> A、B、C、E 都是实际跑通的片子，它们的措辞背后有对照实验。
> **D 的六条是为了示范"这一槽长什么样"而写的，不构成"这样写有效"的证据。**
> 照 [VALIDATION](../VALIDATION.zh-CN.md) 的纪律：把未验证的当成已验证是代价最高的错误。
>
> **它为什么仍然必须在这里**：照[宪法](constitution.zh-CN.md)第四条，
> 每个槽的示例要来自不同片子，任何一部的出现次数都不该明显多于其他。
> 如果这六个槽的示例全从 A 或 B 里取，那两部片子就会变成默认答案——
> 读者不是在填槽，是在补全一份见过五遍的模板。
> **D 的作用是把这些槽的示例打散到六个互不相干的题材上，制造斥力。**

### D1 · 末态的弱强对比

```text
弱：  两个人继续弄那束花
强：  末态：花艺师左手持花束；剪刀回到工作台右侧
```

### D2 · 情绪落到可观察线索

```text
弱：  她不愿意让他走
强：  她的视线从他脸上移开，落到他身旁的空处；眼睑垂下；
      嘴角短暂上扬又落回；胸口起伏一次，被压住
```

### D3 · 术语双写

```text
rack focus：焦点从前景的叶片移到它身后的人。叶片转虚，人脸由虚转实。
bullet time：冻结球棒击中球的瞬间；镜头顺时针绕接触点环绕，碎屑悬在空中。
```

### D4 · 参考素材写两半

```text
@image1 控角色的脸、发型和外套。不要用它的背景或构图。
@video1 控运动路径、走位和切点。不要用它的外观、材质或场景。

```

```text
          转场只用同形物匹配与动作接力。

```

## 案例 E · 限色套印 MG（一部科幻电影的二维改编）

2026-08-10。**第一个走"先对方向再填槽"流程的片子**，四段 15s 接龙跑完。
六版迭代，v6 是成片版。四份完整提示词留在原项目目录（未随 repo 发布），
本节只放**可抄的元素**。

### E1 · 片型术语合成（与案例 B 零重叠）

```text
片型：  科幻电影预告片的二维动画改编
        限色丝网套印动画 + 粗野主义海报构图 + 新黑色电影剪影语汇
        参考限色套印的电影海报
        配平：禁止三维透视渲染 / 禁止立体建模 / 禁止写实体积光与光晕 /
             禁止皮肤质感与肤色渐变 / 禁止 CG 反射与高光
```

三步推导（配平的正确用法）：
- `限色丝网套印` 借**限色大色块＋套印错位＋纸张颗粒**，默认偏置是**低对比复古土色** → 追加"高对比，不要复古低饱和"
- `新黑色电影` 借**逆光剪影与雨夜**，默认偏置是**写实体积光、胶片颗粒、真实皮肤** → 这是禁令的主要目标
- `限色动画` 默认偏置是**低帧廉价感** → 用 pose-to-pose 的定格＋爆发抵消，不靠禁令

> ⛔ **对照 B1 看**：两套术语指向的方向几乎相反（B1＝高密度信息叠层＋高饱和三色，
> E1＝大色域＋极端负空间）。**把 B1 搬到这部片子上，是本 skill 记录过最贵的一次错误。**

### E2 · 〔按需〕两槽的判断结果：持续叠层**空着**

这部片子的观感靠**画面上信息少**（一整片单色里一个小黑点）。
压一层持续滚动的界面会削掉它的呼吸 —— 所以那一槽空着。
**这是「没有必填槽」第一次被实际用掉。**（B2/B4 那两套叠层元素对这部片子全部不适用）

### E3 · 三层反向视差（不是叠层）

```text
第一层：整片底色以每秒约半个屏宽持续向左滑动
第二层：雨线／颗粒以约三倍速度向左下斜掠
第三层：前景黑色巨构剪影以更慢速度向右滑动，与底色反向
三层永不停止，即使在急停瞬间也继续移动
```

**与叠层的区别**：叠层是"画面上多压一层信息"，视差是"同一批元素分层以不同速度移动"。
它不吃负空间，反而让**空的部分也在动**。

### E4 · 动画形变与冲击语汇（手法词表的另一个来源域）

**这一组是「每个槽问自己的来源域」那条骨的实例。** 片型术语来自美术体系（套印海报），
而手法词表来自**动画体系**——两者不同源。前三版都在平面设计语汇里翻（负空间/色块/擦除/分屏），所以加不上去。

```text
冲击帧：每一次视觉重音都配一个单帧纯白或黑白反相，只持续一帧
速度线：重音发生时，放射状速度线自画面四边向重音点集中，或自主体向外爆开，持续约三帧
挤压拉伸：快速移动的色块与形体在加速时纵向拉长，停止时横向压扁再弹回原形
残影拖尾：高速移动的主体拖出三到五个半透明残影，残影颜色比主体浅
过冲回弹：每一次跳进、弹入、落位都先过冲越过目标，再回弹到位
元素增殖：在两帧内复制成五个横向排开，各自过冲，再高速合回一个
速度变化：本段内出现两次急停后倒放两帧再恢复正向
变速：这一段以两倍速播放
```

### E5 · 自加的槽：色彩脚本

现有槽装不下"每一段换一个主色域"这件事（它管全片的段落色彩逻辑，与"风格"作用域不同），所以立为新槽：

```text
色彩脚本：段1 青灰＋品红霓虹（系统／雨）→ 段2 橙黄沙尘（过去／真实之物）
          → 段3 品红＋电子青（被制造的亲密）→ 段4 白＋纯黑（停下来）
          段间切换＝两帧内整屏换色，不是渐变过渡
```

⚠️ **踩过的坑**：色彩脚本写了「除三色外不出现第四色相」，角色槽又写了「蓝紫齐刘海」——
两条锁互撞，模型执行了角色槽。修法：**主色域三色 ＋ 角色自带色不计入**。

### E6 · 节拍骨架段（数值与描述双写）

```text
配乐是每分钟一百三十二拍，每拍间隔零点四五秒，十五秒共三十三拍。
密集鼓点，底鼓每拍踩一次，军鼓在中段滚奏，出现双踩。
画面的视觉重音落在鼓点上。第九拍到第十八拍鼓点密度翻倍，间隔零点二三秒，画面重音同步加密。
第三十一拍所有乐器与运动一起急停，留两拍完全静默。
```

数值（BPM／秒／拍数）与描述（密集鼓点／双踩／滚奏／急停留白）**两种都写**，
因为只有数值那一半被观测过，描述那一半从未测过——两种都写才不漏。

### E7 · 接龙的「延续／清除」二选一 —— 两个实例

**这一组是那条骨的实例。** 上一段的末态是既成条件，对里面每个主体必须二选一：

```text
清除（段3，首帧带一件上一段的道具）：
  「<那件道具>在两帧内被<新主色>完全吞没并彻底消失，本段不再出现<该物>、<同类物>或任何<该类别>形象。
    随即<新主体>自画面下缘一行行被扫描线重建」

延续（段4，首帧带一层可用的元素）：
  「底色在两帧内从<上一段主色>退成<本段主色>，画面上原有的<那层元素>保留不变，
    同时每颗获得一圈极细的<对比色>描边，因此在新底色上依然清晰可读」
```

⚠️ **两者都不写的后果**：v6a 写的是「<道具>的轮廓线被吞没，**同一条轮廓线**随即纵向拉伸变形，
成为<新主体>的轮廓起点」——模型**保住那条轮廓线，把道具放大成了巨像**。
要求 A→B 的变形，但指定的机制是"同一条线拉伸"，而那个机制的物理结果是 **A 变大**。

### E8 · 客观节奏测量（方法，不是元素）

脚本随本 skill 发布：[`tools/analyze_rhythm.py`](../tools/analyze_rhythm.py)，
只依赖标准库与 `ffmpeg`，用法 `python3 tools/analyze_rhythm.py a.mp4 b.mp4 …`。
**必须用 YUV 距离不能只用亮度**——品红与青灰亮度接近，整屏换色在 YAVG 上几乎不动（第一次就测错了）。
指标：YUV 突变处数 / 多 BPM 网格对齐率 / 突变间隔标准差 / 定格占比 / **帧间差中位数（基线运动量）** / 音轨 RMS 峰值间隔。

四段实测：帧间差中位数 0.688 → 0.744 → 0.825 → 0.168（末段收束是设计）。
对照早期版本的 0.08 —— 在这条片子内部，**这一项是版本之间最有区分度的单一指标**。

> ⚠️ **限定：只在受控对照里可比，跨片子的绝对值没有意义。**
> 影响基线的至少有四样：画面对比度（低对比平涂的 YUV 距离天然更小）、题材本身的运动量、
> 镜头运动方式（固定机位 vs 持续推移）、分辨率与帧率。
> 实测：另一条低对比绘本画风的片子四个版本全落在 0.10–0.16，
> 拿它跟本案例的 0.688 比毫无意义——那是两把不同刻度的尺子。
> **正确用法是改一版之前测一次、改完再测一次，看你想改的那个指标动了没有。**
>
> ⚠️ **它测的是画面变化量，不是"动态感"。** 它给不了运动质量（流畅／卡顿／形变），
> 也分不清高数值是"动得好"还是"画面在闪"。**它给的是信号，不是判决。**
> 这一条与[宪法](constitution.zh-CN.md)第十二条同源：动态、节奏、整体调性要靠人看回放。

> 详见 [observations.zh-CN.md](observations.zh-CN.md)：这条片子贡献的逐模型观测（裸 base64、
> moderation 随机性、未指定槽位沿接龙链传染、画面内文字触发人声）全部在那里，不在本文件。
